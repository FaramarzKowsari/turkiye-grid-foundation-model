Complete project guide

What the project does, why it matters, and what would count as evidence.

This page explains the project without requiring a machine-learning background, then progressively opens the technical details.

The simplest version

Think of Türkiye's electricity system as a living network whose behavior is visible through several clocks at once. One clock measures how much electricity people and industry are consuming. Another measures how much electricity is being produced from solar, wind, hydro and other sources. A third records the price formed in the day-ahead market.

Ordinary forecasting studies often build a separate model for each clock. This project asks whether one model can learn the common rhythm underneath all three while still respecting their differences.

The central idea: if rising renewable generation changes the generation mix, and load and generation conditions affect the market, then a model may learn useful shared structure. But shared learning is not automatically better. It can also make one task worse. The experiment is designed to measure both possibilities.
Scientific design

Four questions, not one leaderboard

1. Transfer

Does the joint model beat strong models that do not share representations?

2. Horizon

Does joint learning help one hour ahead but fail twenty-four hours ahead, or vice versa?

3. Regimes

Do high renewable shares, demand ramps or extreme prices change the benefit of sharing?

4. Uncertainty

When the model says it is 90% confident, do approximately 90% of held-out outcomes actually fall inside the interval?

Negative transfer

If one shared representation damages a task, that is a scientifically meaningful finding rather than something to hide.

Out-of-time testing

The main test is later in time than training. This is harder and more realistic than randomly mixing hours from the same period.

Why raw data are not simply committed to GitHub

The repository is software and research infrastructure. Third-party source records remain subject to the source terms. The safer reproducibility pattern is to preserve retrieval instructions, exact source identifiers, hashes and a data manifest, while researchers obtain the source data through the official service.

How one hour becomes a training example

The default context is the previous 168 hours: one full week. From that history, the model predicts three target variables at +1, +6 and +24 hours. That creates nine forecast outputs for one forecast origin.

Model

A compact Transformer before a giant one

The phrase “foundation model” is used here as a research direction: one shared temporal representation that can support multiple grid tasks and later adaptation. The current v0.1 model is intentionally compact. Calling a model foundational does not require pretending that a small baseline is already a massive pretrained model.

Starting compact creates something more valuable at this stage: a reproducible reference point. If a larger pretrained architecture is introduced later, its improvement can be measured against a known baseline instead of appearing without context.

What can fool an electricity forecasting paper?

Temporal leakage

Randomly mixing future and past hours can make performance look better than genuine forward forecasting.

Holdout tuning

If a researcher repeatedly changes the model after seeing holdout scores, the holdout is no longer an untouched test.

Weak baselines

A complex model is not impressive if it is compared only with an easy baseline. Seasonal patterns in electricity are strong.

Mean error only

A low average error can conceal failure during unusual periods. Regime analysis and uncertainty matter.

Compute drift

A protocol that is too expensive to finish encourages post-hoc compromises. Runtime must be measured before freezing the study.

Selective reporting

If only favorable targets or horizons survive into the paper, the evidence is distorted. The final analysis family must be frozen.

Uncertainty

A forecast should know when it may be wrong

The Transformer outputs a mean forecast and a positive scale. That gives a probabilistic estimate, but neural uncertainty can be miscalibrated. The project therefore also supports split-conformal calibration: residuals from a separate calibration period determine an empirical radius for prediction intervals.

The question is not merely whether intervals are wide. The evaluation measures whether their observed coverage matches the promised coverage and how much width was required to achieve it.

Why the project can remain useful even if the Transformer loses

A credible study can discover that joint representation learning does not consistently beat strong seasonal or task-specific models. That would identify limits of cross-task transfer in a real electricity market, especially if the result is stable across horizons and regimes.

The repository is built to make that outcome publishable rather than embarrassing: the scientific object is the hypothesis, not the model's reputation.

Türkçe kısa açıklama

Bu proje Türkiye elektrik sistemindeki tüketim, yenilenebilir üretim ve Gün Öncesi Piyasası PTF verilerini aynı zaman modeli içinde öğrenmenin gerçekten fayda sağlayıp sağlamadığını araştırır. Amaç sadece daha düşük hata değildir; modelin farklı zaman ufuklarında, olağan dışı piyasa koşullarında ve belirsizlik altında ne kadar güvenilir kaldığı da ölçülür. Gerçek veriyle doğrulayıcı sonuç henüz üretilmemiştir.

Resumen en español

El proyecto estudia si una representación temporal compartida puede aprender conjuntamente consumo eléctrico, generación renovable y precio diario de mercado en Türkiye. La evaluación será cronológica, incluirá incertidumbre calibrada y conservará resultados negativos. La versión actual es infraestructura de investigación; todavía no presenta resultados confirmatorios con datos reales.
