# About Türkiye Grid Foundation Model

Türkiye Grid Foundation Model is a reproducible research-software project for studying cross-task temporal transfer in Türkiye's electricity system. The empirical design joins official EPİAŞ hourly consumption, source-level generation and day-ahead market-clearing price into one leakage-resistant forecasting problem.

The project includes a data contract, authenticated source client, chronological evaluation rules, probabilistic forecasting, conformal calibration, compute-budget safeguards, synthetic CI fixtures, an empirical data-audit trail, a draft confirmatory research protocol and a manuscript scaffold that refuses to invent results before the frozen study exists.

**Current status — v0.2.1 empirical open-science milestone:** the bounded January 2024 EPİAŞ audit and corrective generation-accounting audit are complete; the v0.2.1 software snapshot is archived on Zenodo; and an accepted public OSF Open-Ended Registration records the current lifecycle state. No confirmatory forecasting-superiority claim is made. The confirmatory holdout remains undefined and untouched.
